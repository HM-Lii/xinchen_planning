# 基于行为/间隙搜索、五次多项式横向候选与纵向 QP 的高速公路轨迹规划方案

> 适用场景：结构化多车道高速公路、动态周车、滚动时域重规划、轨迹点直接驱动车辆的模拟器  
> 设计目标：安全完成环路行驶，在满足车道、碰撞、加速度和 jerk 约束的前提下尽可能接近 50 mph  
> 文档版本：1.0  
> 日期：2026-08-21

---

## 1. 方案摘要

本文采用以下折中架构：

\[
\boxed{
\text{车道行为与目标间隙搜索}
+
\text{少量五次多项式横向候选}
+
\text{纵向 SVA/Jerk QP}
+
\text{笛卡尔轨迹最终校验}
}
\]

其核心分工是：

- **搜索层**只处理真正离散、非凸、带逻辑分支的变量，例如保持车道、左变道、右变道、目标间隙、从某辆车前方或后方通过、立即变道或延迟变道；
- **五次多项式层**根据搜索层给出的目标车道和粗略变道时机，快速生成少量连续的横向候选；
- **纵向 QP 层**在固定的车道、间隙和通行顺序下，连续优化纵向位置、速度、加速度与 jerk；
- **最终校验层**按照模拟器的 0.02 s 采样方式，对完整二维轨迹检查碰撞、车道边界、总加速度、总 jerk 以及新旧轨迹拼接连续性。

这不是“完整终端状态轨迹采样”。完整终端状态采样通常会离散枚举目标位置、目标速度、目标加速度、开始时间和完成时间等大量变量。本文只保留其中具有离散拓扑意义的部分，将连续变量交给 QP，避免候选数爆炸和终端状态量化误差。

---

## 2. 问题定义

模拟器每隔

\[
\Delta t_{\text{sim}}=0.02\text{ s}
\]

发送主车状态、尚未执行的历史轨迹、地图航点以及周围车辆状态。规划器返回一组按固定时间间隔排列的二维轨迹点：

\[
\mathcal T=
\{(x_0,y_0),(x_1,y_1),\ldots,(x_{N-1},y_{N-1})\}
\]

模拟器按照这些点依次控制车辆，因此点列同时编码了路径和速度。若按二维位置差分，则：

\[
\mathbf v_k \approx
\frac{p_{k+1}-p_k}
{\Delta t_{\text{sim}}},
\qquad
v_k=\|\mathbf v_k\|_2
\]

\[
\mathbf a_k \approx
\frac{\mathbf v_{k+1}-\mathbf v_k}
{\Delta t_{\text{sim}}}
\]

\[
\mathbf j_k \approx
\frac{\mathbf a_{k+1}-\mathbf a_k}
{\Delta t_{\text{sim}}}
\]

因此最终约束检查应使用二维向量范数，而不是只检查标量车速变化。

规划结果需要满足：

- 无碰撞；
- 正常行驶保持在车道内；
- 只在安全条件下变道；
- 尽可能接近 50 mph，即约

\[
v_{\text{limit}}=22.35\text{ m/s}
\]

- 总加速度不超过 \(10\text{ m/s}^2\)；
- 总 jerk 不超过 \(10\text{ m/s}^3\)；
- 重规划前后的轨迹连续平滑；
- 能在环形道路上稳定运行至少一圈。

## 3. 为什么采用这种设计

### 3.1 整体问题是离散与连续变量混合的非凸问题

高速公路中的一个慢车场景通常至少存在以下互斥选择：

\[
\text{FOLLOW}
\quad\lor\quad
\text{PASS LEFT}
\quad\lor\quad
\text{PASS RIGHT}
\]

进入目标车道时，又存在：

\[
\text{进入后车前方}
\quad\lor\quad
\text{等待后车通过后进入其后方}
\]

这些是逻辑“或”关系，对应彼此分离的可行域。单个凸 QP 无法自然地同时决定这些拓扑，因此应由搜索或候选枚举显式处理。行为规划、状态格规划以及组合机动推理的相关工作都体现了这一分工思想 [3][4][5][7]。

一旦确定：

- 目标车道；
- 目标间隙；
- 与关键车辆的前后关系；
- 大致开始时间和变道持续时间；

问题就会变成固定拓扑下的连续轨迹优化，速度、加速度、jerk 和安全间距约束更容易写成线性约束或凸二次目标。

因此，基本原则是：

\[
\boxed{\text{非凸拓扑交给搜索，连续细节交给优化}}
\]

---

### 3.2 为什么不完整采样所有终端状态

完整终端状态采样可能枚举：

\[
x_T=
[s_T,v_T,a_T,d_T,\dot d_T,\ddot d_T,t_{\text{start}},T]
\]

假设分别采样：

- 3 个目标车道；
- 4 个开始时间；
- 5 个变道持续时间；
- 5 个目标速度；
- 3 个目标加速度；
- 3 个目标纵向位置或间隙；

单层候选数已经达到：

\[
3\times4\times5\times5\times3\times3=2700
\]

其中大量候选彼此非常相似，但都需要生成轨迹、预测动态障碍物、进行碰撞检查和动力学验证。

完整采样还会产生量化问题。例如真实可行的终端速度可能是：

\[
v_T=19.7\text{ m/s}
\]

而采样集合只有：

\[
\{18,20,22\}\text{ m/s}
\]

规划器可能在有限候选中找不到更安全、更平滑的解。终端流形与多项式轨迹采样适合表达多种运动模式，但在实时工程中通常需要有选择地限制采样维度 [1][2]。

本文只采样或搜索具有拓扑意义的变量：

\[
\boxed{
\text{目标车道、目标间隙、通行顺序、开始时间档位、变道时长档位}
}
\]

而将下列连续变量交给 QP：

\[
\boxed{
s(t),\ v(t),\ a(t),\ j(t)
}
\]

这样既保留多拓扑探索能力，又减少离散误差。

---

### 3.3 为什么横向采用少量五次多项式候选

标准高速公路的横向目标通常非常明确：

- 保持当前车道中心；
- 从当前车道中心平滑进入左车道中心；
- 从当前车道中心平滑进入右车道中心。

在给定初末横向位置、速度和加速度后，五次多项式可以闭式求解：

\[
d(\tau)=
c_0+c_1\tau+c_2\tau^2+c_3\tau^3+c_4\tau^4+c_5\tau^5
\]

满足：

\[
d(0)=d_0,\quad
\dot d(0)=\dot d_0,\quad
\ddot d(0)=\ddot d_0
\]

\[
d(T)=d_{\text{target}},\quad
\dot d(T)=0,\quad
\ddot d(T)=0
\]

它具有以下优势：

- 生成开销极低；
- 初末状态可精确连接；
- 位置、横向速度和横向加速度连续；
- 通过改变变道持续时间 \(T\) 可直接控制横向激烈程度；
- 非常适合规则车道中心到中心的标准变道 [1][2]。

但五次多项式只是一种连接曲线，不会自动决定：

- 应进入哪个交通间隙；
- 变道时应加速还是减速；
- 是否会被目标车道后车追上；
- 总二维加速度和 jerk 是否超限。

因此它应作为**行为搜索之后的横向候选生成器**，而不是完整规划器。

---

### 3.4 为什么纵向交给 QP，而不是继续采样目标速度

固定车道、间隙和通行顺序后，纵向规划可以采用状态：

\[
z_k=
[s_k,v_k,a_k]
\]

以 jerk 为控制量：

\[
u_k=j_k
\]

在每个离散区间内假设 jerk 恒定，可以得到线性离散动力学。速度、加速度、jerk、前车上界和目标间隙下界大多可以形成线性约束，而接近限速、降低加速度和降低 jerk 可以形成凸二次目标。

与离散采样目标速度相比，QP 可以直接在连续空间中找到：

\[
v_T=19.7\text{ m/s}
\]

而不必从少量速度档位中选择。ST 图中先搜索交通间隙或通行顺序，再为每个固定间隙求解 QP，是已有研究中经过验证的“搜索 + 优化”组合方式 [6][8]。

---

### 3.5 为什么保留 Top-K，而不是行为层只选 Top-1

行为层使用的是粗略预测和近似代价：

- TTC；
- 预计间隙；
- 粗略加速度需求；
- 车道平均速度；
- 变道收益；
- 不确定性。

粗略最优的行为不一定能通过后续精确 QP 和二维动力学检查。因此行为搜索不应立即锁死单个方案，而应保留：

\[
K=2\sim4
\]

个最有希望的拓扑，让下层轨迹生成和优化做最终比较。

这可以缓解分层架构中的一个典型问题：

\[
\text{行为层看起来可行}
\not\Rightarrow
\text{最终轨迹可行}
\]

### 3.6 为什么不默认搜索密集路径点

在不规则自由空间中，搜索 \((s,d)\) 路径点能够决定从障碍物左侧还是右侧绕行，并为后续优化构造空间走廊。但在本文的规则三车道高速公路中：

- 横向可行目标主要就是当前、左、右三个车道中心；
- 道路边界规则，没有泊车、掉头和复杂静态障碍绕行；
- 主要困难来自动态车辆的到达时间、闭合速度和目标间隙，而不是几何上“从哪一侧绕”；
- 只搜索 \((s,d)\) 缺少时间维度，仍需假设速度才能判断动态碰撞。

因此密集路径点搜索在正常变道中容易重复行为层已经完成的车道拓扑选择，却没有直接解决动态时序问题。本文只在以下情况按需启用路径点搜索或路径走廊优化：

- 施工区或道路局部收窄；
- 障碍物部分侵入车道；
- 周车长时间压线，需要车道内偏移；
- 需要先横向避让再回到车道中心；
- 地图边界或车道中心线不规则。

---

### 3.7 为什么不直接运行完整时空轨迹格搜索

直接搜索：

\[
(s,d,v,a,t)
\]

可以同时表达路径、速度和动态碰撞，能力最完整，但维度高、分支多，且离散化容易导致漏解和相邻周期候选跳变。对只有三条规则车道的场景，完整时空格会把大量计算用于重复探索明显不合理的状态。

本文吸收轨迹搜索中最有价值的部分，只保留：

- 变道开始时间；
- 变道持续时间；
- 目标间隙；
- 与周车的前后顺序；

这些直接影响动态可行性的离散参数。精确速度和加速度则由连续 QP 求解。因此该方案可以理解为：

\[
\boxed{
\text{长时域低分辨率行为搜索}
+
\text{短时域聚焦轨迹采样}
+
\text{连续优化}
}
\]

它不是完全放弃轨迹搜索，而是利用车道语义将其压缩到少量高价值候选。

## 4. 总体架构

```text
Simulator Telemetry
        │
        ▼
历史轨迹时间对齐、环形 s 展开、规划初始状态重建
        │
        ▼
周车跟踪与多时刻轨迹预测
        │
        ▼
车道 / 目标间隙 / 前后关系行为搜索
        │
        ▼
保留 Top-K 行为拓扑
        │
        ▼
采样少量开始时间与变道持续时间
        │
        ▼
生成五次多项式横向候选 d(t)
        │
        ▼
依据横向占道过程构造纵向 ST 可行走廊
        │
        ▼
求解纵向 SVA / Jerk QP
        │
        ▼
组合为 Frenet 时空轨迹并转换到 Cartesian
        │
        ▼
碰撞、车道、总加速度、总 jerk、拼接连续性密集检查
        │
        ▼
选择总代价最低的可行轨迹
        │
        └── 全部失败 → 当前车道内受 jerk 限制的安全制动
```

用集合形式表示，规划器求解：

\[
\min_{b\in\mathcal B}
\min_{\tau_d\in\mathcal T_d(b)}
\min_{z,u}
J_{\text{behavior}}(b)
+
J_{\text{lat}}(\tau_d)
+
J_{\text{lon}}(z,u)
+
J_{\text{consistency}}
\]

其中：

- \(b\)：行为与间隙拓扑；
- \(\tau_d\)：与该行为匹配的横向五次多项式候选；
- \(z,u\)：纵向 QP 状态和 jerk；
- 每一层先执行硬约束筛选，再比较软代价。

## 5. 时间对齐与规划初始状态

### 5.1 从历史轨迹末端开始规划

如果模拟器还未执行的历史轨迹有 \(N_{\text{prev}}\) 个点，则新轨迹真正开始执行的延迟为：

\[
t_{\text{delay}}
=
N_{\text{prev}}\Delta t_{\text{sim}}
\]

新规划不能从当前遥测状态直接开始，而应：

1. 保留尚未执行的历史轨迹；
2. 以历史轨迹末端作为新规划的初始位置；
3. 用历史轨迹最后若干点估计初始速度、加速度、航向和横向状态；
4. 将周车预测推进到 \(t_{\text{delay}}\)；
5. 从该未来时刻继续生成新轨迹。

否则规划状态和轨迹实际执行状态存在时间错位，容易造成拼接速度跳变和碰撞判断错误。

---

### 5.2 环形道路的纵向坐标必须展开

道路总长度记为 \(L\)。内部规划应使用连续展开的纵向坐标：

\[
s_{\text{unwrap}}
\]

地图查询时再执行：

\[
s_{\text{map}}
=
s_{\text{unwrap}}\bmod L
\]

例如主车位于 \(s=6940\text{ m}\)，前车位于 \(s=5\text{ m}\)，前向环形距离应为：

\[
\Delta s_{\text{front}}
=
(5-6940+L)\bmod L
\]

而不是将前车判断为位于主车后方数千米。

---

## 6. 周车预测与车道占用建模

### 6.1 基础预测

最简单的纵向预测采用恒速模型：

\[
\hat s_i(t)
=
s_i(0)+v_i t
\]

横向可采用：

\[
\hat d_i(t)=d_i(0)
\]

但只用当前车道编号并不可靠。应根据连续帧按车辆 ID 估计：

\[
\dot s_i,\quad
\dot d_i
\]

当车辆：

- 靠近车道边界；
- 横向速度明显；
- 已经压线；
- 车身包络同时覆盖两条车道；

应将其预测占用扩展到两条车道。

---

### 6.2 预测不确定性

恒速预测适合该模拟器的基础版本，但存在以下风险：

- 周车主动加减速；
- 周车突然切入；
- 周车开始变道但当前横向速度尚不明显。

工程上可以通过以下方式增加鲁棒性：

- 随预测时域扩大纵向、横向安全包络；
- 对疑似变道车辆同时生成“保持车道”和“继续变道”两种预测；
- 行为层使用保守 TTC 和最小安全间隙；
- 对高不确定性候选增加代价；
- 每个重规划周期重新评估，并保留安全制动回退。

---

## 7. 车道行为与目标间隙搜索

### 7.1 搜索状态

行为节点可以表示为：

\[
B_k=
(
l_k,\,
m_k,\,
g_k,\,
o_k,\,
q_k,\,
t_k
)
\]

其中：

- \(l_k\)：当前或目标车道；
- \(m_k\)：行为模式；
- \(g_k\)：目标间隙；
- \(o_k\)：相对通行顺序；
- \(q_k\)：行为阶段；
- \(t_k\)：粗粒度决策时刻。

行为模式可包含：

\[
\{
\text{KEEP},
\text{FOLLOW},
\text{PREPARE-LC},
\text{LC-LEFT},
\text{LC-RIGHT},
\text{EMERGENCY}
\}
\]

目标间隙可以用目标车道上的前后车辆 ID 表示：

\[
g=(\text{front\_id},\text{rear\_id})
\]

相对通行顺序用于表达：

- 在目标后车前方完成插入；
- 等待目标后车通过后进入其后方；
- 保持在当前前车后方；
- 加速后从某辆车前方通过。

这比只搜索 `LCL/LCR` 更完整，因为“左变道”本身没有说明主车准备进入哪一个动态间隙。

---

### 7.2 行为边

可用行为边包括：

- 保持当前车道并巡航；
- 保持当前车道并跟车；
- 立即左变道；
- 立即右变道；
- 延迟一段时间后左变道；
- 延迟一段时间后右变道；
- 继续上一周期已承诺的变道；
- 放弃未开始的变道并保持车道；
- 当前车道内受限减速。

已经开始并明显跨越车道线的变道不应因普通代价波动而频繁中止。只有出现新的严重安全风险时才允许生成明确的中止或回退轨迹。

---

### 7.3 目标间隙提取

对每条候选车道，在若干未来时刻：

1. 使用展开后的 \(s\) 对预测车辆排序；
2. 将相邻车辆之间的区域构造成候选间隙；
3. 根据车辆长度和安全裕度缩小间隙；
4. 计算主车进入该间隙所需的粗略纵向速度和加速度；
5. 淘汰无法在规划时域内到达的间隙。

候选间隙不仅包括当前存在的几何空隙，也可以包括预测后会打开的间隙，例如：

> 先让目标车道快速后车通过，再进入其后方。

---

### 7.4 行为层硬剪枝

以下情况直接淘汰，不进入下层：

- 目标车道不存在；
- 目标间隙在整个候选时间窗内都小于车辆包络和安全距离；
- 目标后车闭合速度过大、TTC 过小；
- 粗略估计所需纵向加速度超过安全上限；
- 粗略最小变道时间大于可用时间窗；
- 周车预测显示另一辆车正在向同一间隙切入；
- 变道过程必然同时与原车道和目标车道车辆冲突。

---

### 7.5 行为代价

可以定义：

\[
J_B=
w_pJ_{\text{progress}}
+w_sJ_{\text{safety}}
+w_cJ_{\text{comfort-est}}
+w_lJ_{\text{lane-change}}
+w_hJ_{\text{hysteresis}}
+w_uJ_{\text{uncertainty}}
\]

其中：

- \(J_{\text{progress}}\)：预计速度和纵向推进损失；
- \(J_{\text{safety}}\)：TTC、最小间距和安全裕度；
- \(J_{\text{comfort-est}}\)：粗略所需加速度、减速度和变道时间；
- \(J_{\text{lane-change}}\)：抑制无收益的频繁变道；
- \(J_{\text{hysteresis}}\)：惩罚相对上一周期的行为切换；
- \(J_{\text{uncertainty}}\)：对预测不确定性高的间隙增加代价。

碰撞、道路越界和明显动力学不可行应作为硬约束，不应只增加软代价。

---

### 7.6 搜索算法选择

该场景只有三条车道，行为分支很少，不需要建立大规模网格。推荐使用：

- 有限深度 Dijkstra 或 A*；
- 动态规划；
- Beam Search；
- 小规模 best-first search。

工程上最简单的是：

1. 扩展未来若干个行为阶段；
2. 每层只保留代价最低的若干节点；
3. 最终输出 Top-K 个不同拓扑。

行为层适合较长时域和较低分辨率，轨迹层适合较短时域和较高分辨率。

---

## 8. 五次多项式横向候选

### 8.1 候选参数

对每个 Top-K 行为拓扑，只采样少量：

- 变道开始时间 \(t_{\text{start}}\)；
- 变道持续时间 \(T_{\text{LC}}\)。

例如初始测试可使用：

\[
t_{\text{start}}
\in
\{0,\ 0.5,\ 1.0,\ 1.5\}\text{ s}
\]

\[
T_{\text{LC}}
\in
\{3.5,\ 4.0,\ 4.5,\ 5.0\}\text{ s}
\]

这些只是初始调参范围，不是固定标准。后续应围绕上一周期最优参数自适应加密，减少候选切换：

\[
T_{\text{LC}}
\in
\{
T_{\text{prev}}-0.5,\,
T_{\text{prev}}-0.25,\,
T_{\text{prev}},\,
T_{\text{prev}}+0.25,\,
T_{\text{prev}}+0.5
\}
\]

---

### 8.2 分段结构

横向候选可写成三段：

\[
d(t)=
\begin{cases}
d_{\text{continue}}(t),
&0\le t<t_{\text{start}}\\[4pt]
d_{\text{quintic}}(t-t_{\text{start}}),
&t_{\text{start}}\le t<t_{\text{start}}+T_{\text{LC}}\\[4pt]
d_{\text{target}},
&t\ge t_{\text{start}}+T_{\text{LC}}
\end{cases}
\]

其中：

- 延迟阶段继续当前已承诺轨迹，或保持当前车道；
- 变道阶段使用五次多项式；
- 完成后保持目标车道中心。

如果上一周期已经处于变道中，应从上一条轨迹末端的：

\[
[d_0,\dot d_0,\ddot d_0]
\]

继续连接，而不是重新从车道中心发起一条全新曲线。

---

### 8.3 时间域与空间域的选择

可以使用：

\[
d(t)
\]

也可以使用：

\[
d(s)
\]

本文推荐在该模拟器中优先使用时间域 \(d(t)\)，原因是：

- 输出点按固定 0.02 s 时间间隔执行；
- 加速度和 jerk 约束也是时间域物理量；
- 变道完成时间和目标车流间隙具有直接时序意义。

但应注意，Frenet 横向时间导数不完全等于笛卡尔横向动力学。在弯道和纵向速度变化明显时，最终仍必须对笛卡尔轨迹进行数值检查。

---

### 8.4 横向候选早期检查

在进入纵向 QP 前，先检查：

- \(d(t)\) 是否越过道路边界；
- 横向速度、加速度和 jerk 是否明显超限；
- 车辆包络在变道过程中是否与静态道路边界冲突；
- 候选是否与上一周期横向轨迹存在明显不连续；
- 变道持续时间是否过短。

这些只是早期剪枝，最终判定仍以组合后的完整二维轨迹为准。

---

## 9. 根据横向候选构造纵向 ST 走廊

### 9.1 为什么每条横向候选都需要独立的 ST 走廊

同一个左变道行为，3.5 s 和 5.0 s 的横向候选会在不同时间进入目标车道，因此受到的车辆约束不同：

- 何时开始与目标车道后车存在冲突；
- 何时不再受到原车道前车约束；
- 横跨车道线期间是否同时占用两条车道；
- 是否能在目标后车追上之前完成插入。

因此不能先求一个与横向轨迹无关的纵向速度，再简单叠加变道曲线。合理流程是：

\[
\boxed{
d(t)\text{ 候选}
\rightarrow
\text{占道时序}
\rightarrow
\text{ST 约束}
\rightarrow
\text{纵向 QP}
}
\]

---

### 9.2 车身占道集合

在每个时刻，根据主车车身包络而不是仅根据中心点 \(d(t)\)，计算主车占用车道集合：

\[
\mathcal L_{\text{ego}}(t)
\]

变道中间阶段通常有：

\[
\mathcal L_{\text{ego}}(t)
=
\{\text{current lane},\text{target lane}\}
\]

此时安全约束必须同时考虑两条车道中的相关车辆，不能在中心点刚越过车道线时立即删除原车道约束。

---

### 9.3 固定通行拓扑后的纵向约束

假设行为层已经确定主车进入目标车道前车 \(f\) 与后车 \(r\) 之间，则可构造：

前车约束：

\[
s_k
\le
\hat s_{f,k}
-
D_{f,k}
\]

后车约束：

\[
s_k
\ge
\hat s_{r,k}
+
D_{r,k}
\]

其中安全距离可包含：

- 车辆几何长度；
- 固定缓冲距离；
- 速度相关时间头距；
- 预测不确定性膨胀量。

例如前车约束可写成仿射形式：

\[
s_k+\tau_f v_k
\le
\hat s_{f,k}-D_0
\]

它对 \(s_k,v_k\) 仍是线性约束。

目标后车安全性不能只依赖 QP 中的几何下界。行为层还应提前检查后车 TTC、闭合速度以及所需减速度，因为该模拟器中的周车未必会主动礼让主车。

---

## 10. 纵向 SVA/Jerk QP

### 10.1 状态与动力学

选择状态：

\[
z_k=
\begin{bmatrix}
s_k\\v_k\\a_k
\end{bmatrix}
\]

控制量：

\[
u_k=j_k
\]

在 QP 离散区间 \(\Delta t\) 内假设 jerk 恒定：

\[
a_{k+1}=a_k+j_k\Delta t
\]

\[
v_{k+1}
=
v_k+a_k\Delta t+\frac{1}{2}j_k\Delta t^2
\]

\[
s_{k+1}
=
s_k+v_k\Delta t
+\frac{1}{2}a_k\Delta t^2
+\frac{1}{6}j_k\Delta t^3
\]

这些约束对决策变量是线性的。

QP 的内部步长可以大于模拟器步长，例如 0.1 s 或 0.2 s；求解后根据分段恒定 jerk 的解析表达式重新采样到 0.02 s。最终检查仍必须使用 0.02 s 轨迹点。

---

### 10.2 目标函数

可以使用：

\[
J_{\text{lon}}
=
\sum_{k=0}^{N}
\left[
w_v(v_k-v_{\text{ref},k})^2
+w_a a_k^2
+w_j j_k^2
+w_{\Delta j}(j_k-j_{k-1})^2
\right]
-w_p s_N
\]

其中：

- 速度误差项鼓励接近限速；
- 加速度项提高舒适性；
- jerk 项抑制加速度快速变化；
- jerk 变化项进一步抑制离散节点间的控制抖动；
- 终端推进项鼓励在安全条件下取得更大纵向进度。

---

### 10.3 约束

基础约束包括：

\[
0\le v_k\le v_{\text{limit}}
\]

\[
a_{\min,k}\le a_k\le a_{\max,k}
\]

\[
j_{\min}\le j_k\le j_{\max}
\]

\[
s_{\min,k}\le s_k\le s_{\max,k}
\]

以及初始状态：

\[
s_0=s_{\text{init}},\quad
v_0=v_{\text{init}},\quad
a_0=a_{\text{init}}
\]

为了给二维合成、地图插值和数值差分留出裕度，QP 内部不应直接把纵向加速度和 jerk 卡在 10 的评价上限。正常模式可以采用更舒适的限制，紧急模式才逐步放宽，但仍应低于最终硬上限。

---

### 10.4 求解器

该问题是稀疏、滚动重复求解的凸 QP，适合使用 OSQP 等支持：

- 稀疏矩阵；
- warm start；
- 矩阵结构复用；
- 不可行性检测；

的求解器 [9]。

为了提高实时性，应尽量固定：

- 规划节点数；
- 决策变量排列；
- 约束矩阵稀疏结构。

每周期主要更新：

- 线性项；
- 上下界；
- 初始状态；
- ST 走廊。

---

## 11. 横纵向耦合与总动力学约束

### 11.1 纵向 QP 不能独立保证总加速度

总加速度近似为：

\[
a_{\text{total}}
=
\sqrt{
a_{\text{lon}}^2
+
a_{\text{lat}}^2
}
\]

路径曲率为 \(\kappa\) 时，横向加速度近似为：

\[
a_{\text{lat}}
\approx
v^2\kappa
\]

因此，即使纵向 QP 满足：

\[
|a_{\text{lon}}|\le10
\]

总加速度仍可能超过 10。

---

### 11.2 横向 jerk 与速度强耦合

对于沿固定曲率路径运动的近似情况：

\[
j_{\text{lat}}
=
\frac{d}{dt}(v^2\kappa)
\]

展开可得：

\[
j_{\text{lat}}
=
2va_{\text{lon}}\kappa
+
v^3\frac{d\kappa}{ds}
\]

所以平滑 \(d(t)\) 或 \(d(s)\) 并不自动保证物理横向 jerk 满足上限。

---

### 11.3 推荐处理方式

采用“保守约束 + 少量迭代 + 最终验证”：

1. 由横向候选估计路径曲率和横向动力学；
2. 根据曲率构造速度上限：

\[
v_k
\le
\sqrt{
\frac{a_{\text{lat,max}}}
{\max(|\kappa_k|,\varepsilon)}
}
\]

3. 为纵向加速度预留横向预算；
4. 求解第一次纵向 QP；
5. 用求得的速度重新计算二维加速度和 jerk；
6. 必要时收紧速度或纵向加速度边界，再求解一次；
7. 在 0.02 s 笛卡尔轨迹上做最终差分检查。

如果候选仍超限，应淘汰该候选，而不是放松安全硬约束。

---

## 12. 轨迹组合、输出与最终验证

### 12.1 Frenet 到 Cartesian

对每个输出时刻 \(t_k\)：

1. 从纵向轨迹得到 \(s(t_k)\)；
2. 从横向候选得到 \(d(t_k)\)；
3. 通过参考线映射得到：

\[
(x_k,y_k)
=
\operatorname{FrenetToCartesian}
\left(
s(t_k)\bmod L,\,
d(t_k)
\right)
\]

内部使用展开 \(s\)，只有地图查询时取模。

---

### 12.2 新旧轨迹拼接

输出轨迹由两部分组成：

```text
尚未执行的历史轨迹
+
从历史轨迹末端继续生成的新轨迹
```

新轨迹初始状态必须与旧轨迹末端的：

- 位置；
- 航向；
- 速度；
- 加速度；
- 横向速度；
- 横向加速度；

尽可能一致。

不要只保证位置连续。位置连续但速度或加速度不连续，仍会在 0.02 s 差分中产生极大 jerk。

---

### 12.3 硬约束检查

最终候选需要在完整笛卡尔轨迹上检查：

1. **碰撞检查**  
   使用车辆矩形或膨胀包络，不只使用中心点距离。

2. **车道边界检查**  
   正常模式保持车身在允许车道区域内；变道时允许跨越相邻车道线，但不得越出道路边界。

3. **变道安全检查**  
   检查整个变道时域，而不是只检查起始时刻。

4. **总加速度检查**

\[
\|a_k\|_2<10\text{ m/s}^2
\]

5. **总 jerk 检查**

\[
\|j_k\|_2<10\text{ m/s}^3
\]

6. **拼接点检查**  
   特别检查历史轨迹最后若干点和新轨迹最初若干点。

7. **环路连接检查**  
   验证 \(s\) 跨越零点时地图插值、前后车排序和碰撞检查无跳变。

---

## 13. 候选总代价与选择

只有通过所有硬约束的候选才能参与最终比较：

\[
J_{\text{total}}
=
J_B
+
J_{\text{lat}}
+
J_{\text{lon}}
+
J_{\text{margin}}
+
J_{\text{consistency}}
\]

可包含：

- 预计行驶进度；
- 与限速差距；
- 前后安全裕度；
- 总加速度和 jerk；
- 变道次数；
- 变道时间；
- 与上一周期轨迹的差异；
- 行为切换惩罚；
- 预测不确定性。

安全裕度不应只用“是否碰撞”的二元结果。两个轨迹都无碰撞时，应优先选择最小间距和 TTC 更大的轨迹。

---

## 14. 失败回退

如果所有正常候选均不可行，回退策略应明确且始终可生成：

\[
\boxed{\text{保持当前车道并进行受 jerk 限制的安全减速}}
\]

回退优先级可以是：

1. 继续上一周期仍然安全的轨迹；
2. 当前车道内受限减速；
3. 更强但仍满足硬动力学上限的紧急制动；
4. 只有在原车道已不可避免碰撞且相邻空间明确安全时，才考虑紧急避让。

不能在 QP 无解时随机选择变道，也不能为了获得数值解而放松碰撞约束。

---

## 15. 规划主流程伪代码

```cpp
Trajectory Plan(const Telemetry& input) {
    PlanningState init = AlignToPreviousPathEnd(input);
    init.s = UnwrapLoopS(init.s);

    Predictions predictions =
        PredictSurroundingVehicles(input.sensor_fusion,
                                   init.time_delay);

    std::vector<BehaviorCandidate> behaviors =
        SearchLaneAndGapBehaviors(init, predictions);

    behaviors = KeepTopKDistinctTopologies(behaviors, 3);

    std::vector<PlanResult> valid_plans;

    for (const auto& behavior : behaviors) {
        auto parameter_samples =
            SampleLaneChangeTiming(behavior,
                                   previous_committed_plan);

        for (const auto& param : parameter_samples) {
            LateralTrajectory lateral =
                GenerateQuinticLateralCandidate(
                    init.lateral_state,
                    behavior.target_lane,
                    param.start_delay,
                    param.lane_change_duration);

            if (!PassLateralPrecheck(lateral)) {
                continue;
            }

            STCorridor corridor =
                BuildSTCorridor(
                    behavior,
                    lateral,
                    predictions);

            SpeedQPResult speed =
                SolveLongitudinalSVAJerkQP(
                    init.longitudinal_state,
                    corridor,
                    behavior.target_speed);

            if (!speed.success) {
                continue;
            }

            Trajectory trajectory =
                CombineAndResample(
                    lateral,
                    speed,
                    0.02);

            if (!PassCartesianHardValidation(
                    trajectory,
                    predictions,
                    input.map)) {
                // 可选择收紧速度/加速度预算后再求解一次
                continue;
            }

            valid_plans.push_back(
                EvaluateTotalCost(
                    behavior,
                    lateral,
                    speed,
                    trajectory));
        }
    }

    if (valid_plans.empty()) {
        return GenerateJerkLimitedBrakingFallback(init);
    }

    return SelectLowestCostPlan(valid_plans);
}
```

## 16. 方案优点

### 16.1 正确处理非凸拓扑

目标车道、交通间隙和前后通行顺序由搜索显式展开，不需要让单个凸优化器处理逻辑“或”。

---

### 16.2 避免完整终端状态采样的组合爆炸

只离散真正具有拓扑意义的变量，速度、加速度和 jerk 保持连续优化，候选数量显著降低。

---

### 16.3 适合规则高速公路

三车道高速公路横向自由度有限，标准变道可由少量五次多项式很好地覆盖，无需运行大规模二维路径点搜索。

---

### 16.4 平滑性与硬约束更容易控制

纵向 QP 可以显式约束：

- 速度；
- 加速度；
- jerk；
- 前车距离；
- 目标间隙上下界。

结合历史轨迹末端状态和 warm start，可显著降低滚动重规划抖动。

---

### 16.5 可解释、可测试、易定位问题

每个结果都能追溯到：

- 选择了哪条车道；
- 进入了哪个间隙；
- 采用何种通行顺序；
- 选择了哪个变道持续时间；
- QP 为什么可行或不可行；
- 最终是哪项硬约束淘汰了候选。

这比单个大规模非线性优化器更便于工程调试。

---

### 16.6 模块可以逐步升级

可以先实现：

\[
\text{简单行为枚举}
+
\text{五次横向曲线}
+
\text{纵向 QP}
\]

后续再升级：

- 目标间隙搜索；
- 多模态周车预测；
- 自适应候选采样；
- 路径 QP；
- 更精确的车辆包络；
- 交互式预测与规划。

---

## 17. 方案缺点与风险

### 17.1 横纵向解耦会产生次优性

先固定横向候选，再优化纵向速度，不等价于联合优化全二维轨迹。某条横向曲线可能迫使纵向 QP 过度减速，而另一条未采样的横向曲线可能更优。

**缓解方式：**

- 保留多种变道时间；
- 围绕上一周期最优值局部加密；
- 对最优候选执行一到两轮横纵向交替修正；
- 必要时将横向多项式改为走廊内的路径 QP。

---

### 17.2 依赖周车预测准确性

固定间隙和通行顺序是基于预测得到的。如果周车突然加速、减速或切入，原本可行的轨迹可能迅速失效。

**缓解方式：**

- 预测包络随时间膨胀；
- 多假设预测；
- 高频滚动重规划；
- 安全余量；
- 明确制动回退。

---

### 17.3 五次多项式覆盖能力有限

单段五次多项式适合标准车道中心到中心变道，但对以下情况不够灵活：

- 道路边界不规则；
- 施工区；
- 障碍物部分侵入车道；
- 需要先偏移再回正；
- 需要中途改变横向运动趋势。

此时应增加路径点搜索、状态格或走廊内路径 QP。

---

### 17.4 总二维动力学不能完全由单个纵向 QP 保证

横向加速度和 jerk 与速度、曲率耦合。若只对纵向变量施加 10 的限制，最终二维轨迹仍可能超限。

**缓解方式：**

- 曲率速度上限；
- 横向预算预留；
- 少量迭代；
- 0.02 s 笛卡尔差分硬检查。

---

### 17.5 分层代价难以完全统一

行为层、横向候选层和 QP 层使用不同粒度的代价。若权重设计不一致，可能出现：

- 行为层偏爱某个间隙；
- 下层为实现该间隙付出很大舒适性代价；
- 另一个行为总体上其实更优。

**缓解方式：**

- 行为层保留 Top-K；
- 最终只用完整轨迹总代价做决策；
- 对各项代价归一化；
- 记录每个候选的分项代价并做回放分析。

---

## 18. 适配性分析

### 18.1 高度适配

该方案特别适合：

- 结构化多车道高速公路；
- 标准车道中心明确；
- 主要行为是巡航、跟车、左变道和右变道；
- 动态车辆大致沿车道运动；
- 规划器输出轨迹点，模拟器直接按点执行；
- 需要严格控制速度、加速度和 jerk；
- 需要较强实时性和可解释性。

本文描述的三车道环形高速场景正属于这一类。

---

### 18.2 经过扩展后可适配

通过扩展行为图和间隙定义，可用于：

- 匝道汇入；
- 车道减少；
- 多车道合流；
- 超车后回到原车道；
- 车道内慢速拥堵；
- 需要短暂延迟后再变道的场景。

---

### 18.3 不适合作为唯一方案

以下场景不宜仅依赖该方案：

- 无明确车道的自由空间；
- 复杂路口、多方向交叉交通；
- 施工区和不规则可行域；
- 静态障碍导致多种空间绕行拓扑；
- 低速泊车和掉头；
- 强交互、需要主动协商的密集交通；
- 道路曲率和车辆动力学耦合极强的极限驾驶。

这些场景可增加：

- \((s,d)\) 路径点 DP/A*；
- 状态格或时空轨迹格；
- 多模态交互预测；
- NMPC/SQP；
- 安全走廊优化。

## 19. 与相近方案的比较

| 方案 | 离散搜索内容 | 连续优化内容 | 主要优势 | 主要问题 |
|---|---|---|---|---|
| 只搜索行为 + 单条五次变道 | 车道行为 | 简单速度控制 | 实现最简单 | 对动态间隙和后车闭合处理不足 |
| 完整终端状态轨迹采样 | 车道、时间、位置、速度、加速度等 | 可选后处理 | 表达能力强 | 候选爆炸、量化误差明显 |
| 直接时空轨迹格搜索 | \((s,d,v,t)\) 或更高维状态 | 平滑优化 | 动态可行性表达完整 | 搜索规模大、工程复杂 |
| **本文折中方案** | **车道、间隙、前后关系、变道时机** | **纵向 \(s,v,a,j\)，必要时横向微调** | **拓扑能力、实时性和平滑性均衡** | **依赖预测，存在横纵向解耦次优性** |
| DP 路径 + QP 速度 | 空间绕行路径 | 路径和速度平滑 | 复杂空间障碍能力强 | 对规则高速公路可能过重 |
| 联合 NMPC/SQP | 少量外层行为或混合变量 | 联合二维轨迹 | 耦合建模最完整 | 非凸、初值敏感、实时性和回退复杂 |

## 20. 初始工程参数建议

以下参数只适合作为起始调试范围，应通过仿真回放和统计结果调整：

| 参数 | 建议起始范围 |
|---|---:|
| 行为预测时域 | 6–10 s |
| 纵向 QP 步长 | 0.1–0.2 s |
| 最终输出步长 | 0.02 s |
| Top-K 行为数 | 2–4 |
| 变道开始时间候选 | 0–1.5 s，按 0.5 s 粗采样 |
| 变道持续时间候选 | 3.5–5.0 s |
| 正常纵向加速度舒适范围 | 约 \(-3\) 到 \(2.5\text{ m/s}^2\) |
| 紧急减速度上限 | 低于最终 \(10\text{ m/s}^2\) 硬上限并保留裕度 |
| 正常 jerk 目标范围 | 明显低于 \(10\text{ m/s}^3\) |
| 行为切换冷却 | 结合交通密度与变道完成状态设置 |
| 规划器总时间预算 | 应显著低于一次遥测周期或采用轨迹缓存容忍更低规划频率 |

应区分：

- **舒适目标值**；
- **正常硬边界**；
- **紧急硬边界**；
- **模拟器最终评价上限**。

不要将正常规划一直运行在评价上限附近。

## 21. 测试建议

至少覆盖以下场景：

1. 无周车，持续接近 50 mph；
2. 当前车道存在 40 mph 慢车，左车道安全；
3. 当前车道慢车，但左后车高速逼近；
4. 左右车道均被占用，只能跟车；
5. 目标后车刚好通过后出现可用间隙；
6. 周车主动向主车目标车道变道；
7. 主车变道过程中原车道前车突然减速；
8. 新旧轨迹拼接时历史点较多和较少两种情况；
9. 环形道路 \(s\) 跨越零点；
10. 所有正常候选均不可行，触发制动回退；
11. 连续运行完整一圈以上，检查行为抖动和误差累积；
12. 随机交通流批量回归测试。

建议记录：

- 碰撞次数；
- 越界次数；
- 最大总加速度；
- 最大总 jerk；
- 平均速度与限速差；
- 变道成功率；
- 变道取消次数；
- 最小 TTC；
- QP 不可行率；
- 每周期候选数量和求解时间；
- 行为切换频率；
- 一圈完成率。

---

## 22. 最终设计结论

该场景不需要在完整高维时空中盲目搜索，也不适合把所有终端速度、位置和加速度都离散枚举。最合理的折中是：

\[
\boxed{
\begin{aligned}
\text{搜索层：}&
\text{目标车道、目标间隙、通行顺序、变道时机}\\
\text{横向层：}&
\text{少量五次多项式候选}\\
\text{纵向层：}&
\text{连续 SVA/Jerk QP}\\
\text{验证层：}&
\text{0.02 s 笛卡尔硬约束检查}
\end{aligned}
}
\]

它利用了高速公路车道结构简单的特点，同时保留了对动态车辆非凸通行拓扑的探索能力；通过 QP 避免连续速度变量离散化，并以最终二维校验弥补横纵向分解的误差。

对于本文给定的三车道环形高速模拟器，该方案在以下因素之间取得了较好的平衡：

- 计算复杂度；
- 动态交通适应性；
- 轨迹平滑性；
- 硬约束表达能力；
- 行为稳定性；
- 工程可解释性；
- 后续扩展空间。
