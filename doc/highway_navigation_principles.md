# 高速领航整体原理

## 1. 文档定位

本文说明高速领航规划器的端到端工作原理，重点回答以下问题：

- 为什么采用“行为与空隙搜索 + 固定空间路径 + 纵向 ST/QP + 全轨迹硬校验”的组合。
- 当前车道巡航与未来主动变道是什么关系。
- 一个候选轨迹如何产生、判定、排序、提交和回退。
- 在什么假设下可以讨论正确性，系统不能保证什么。

本文不展开类、接口和字段。数据语义与安全契约见[高速领航架构](highway_navigation_architecture.md)。

## 2. 目标与适用范围

高速领航面向结构化高速公路中的连续巡航、跟车和保守变道。规划器需要同时满足：

- 安全：任何可正常发布的轨迹都必须通过统一的物理安全校验。
- 可解释：能够说明选择了哪条车道、哪个空隙，以及为什么拒绝其他候选。
- 稳定：不能因为相邻周期的小幅感知波动频繁改变意图。
- 可回退：当前车道巡航始终作为基线模式和一等候选保留。
- 可演进：保持车道巡航与主动行为规划共享安全基础，允许独立验证和替换各层实现。

本方案不试图在第一阶段覆盖城区路口、无结构道路、强交互博弈或任意形式的紧急避障。它也不把“求解器有解”等同于“轨迹安全”。

## 3. 核心思想

高速领航把一个高度耦合的问题拆成四层：

1. **离散拓扑层**：决定保持车道还是向相邻车道移动，并选择目标交通空隙。
2. **空间几何层**：为每个拓扑生成一条固定的候选路径。
3. **时间参数层**：在固定路径上求解纵向进度、速度、加速度和 jerk。
4. **物理判定层**：将结果还原为完整笛卡尔轨迹，并执行不可绕过的硬校验。

候选可以抽象为：

```text
Candidate = Behavior + TargetLane + TargetGap + SpatialPath
Trajectory = SpatialPath(PathProgress(t))
```

这种拆分的关键价值是：

- 离散层负责不能由单个凸 QP 自然表达的车道和前后顺序选择。
- 空间层固定“从哪里走”，避免横向形状随着纵向速度反复变化。
- 时间层负责“何时走到哪里”，可以继续利用成熟、稳定的纵向 QP。
- 最终校验直接面对车辆与障碍物的物理占用，不依赖中间模型一定完全正确。

任何一层的成功都不能单独证明候选可发布。只有最终完整轨迹通过硬校验，候选才具有控制资格。

## 4. 单周期端到端流程

每个规划周期以同一时刻、同一份不可变输入快照为起点：

```mermaid
flowchart LR
    A[定位、地图、感知、车辆状态] --> B[不可变 PlanningSnapshot]
    B --> C[跟踪与保守交通预测]
    C --> D[行为、车道与目标空隙枚举]
    D --> E[保守变道准入]
    E --> F[固定空间路径生成]
    F --> G[候选专属 ST 障碍走廊]
    G --> H[纵向 QP]
    H --> I[完整笛卡尔轨迹合成]
    I --> J[全时域硬校验]
    J --> K[可行候选分级排序]
    K --> L[运行模式仲裁]
    L --> M[仅获胜候选提交状态并输出]
```

## 5. 统一时间基准与滚动规划

一个周期内的自车状态、障碍物预测、候选轨迹和安全判定必须共享同一时间原点 `t0`。禁止将上一周期轨迹上的未来点、当前感知位置和不同起点的障碍物预测直接混用。

滚动规划允许保留一小段已经承诺、执行器来不及改变的轨迹前缀，但该前缀必须：

- 有明确上限，目标最大保留时长约为 `0.3 s`。
- 作为本周期完整轨迹的一部分继续接受碰撞和动力学检查。
- 一旦已经不安全，不能用重新规划其后的轨迹掩盖问题。

规划器内部生成并校验完整时域，例如 `8 s`、`0.02 s` 采样；控制接口即使只消费前 `50` 个点，也不能只检查这 `50` 个点。

## 6. 坐标与数据语义

系统明确区分两类纵向坐标：

- `RoadSUnwrapped`：道路或车道参考线上的连续全局里程，用于地图、车道关系和交通对象定位。
- `PathProgress`：沿某一条固定候选路径的实际物理弧长，记为 `p`，用于该候选的纵向优化。

纵向 QP 中的状态含义固定为：

```text
p = PathProgress
v = dp/dt
a = d2p/dt2
j = d3p/dt3
```

`p` 不是道路参考线的 `s`，也不是数组索引或抽象进度比例。每个候选都必须提供从 `p` 到笛卡尔位置、航向和曲率的确定映射。障碍物也必须投影到同一候选路径后，才能构造该候选的 ST 约束。

这一约束避免了最危险的数据语义错误：数值看似合理，但不同模块实际在使用不同的距离定义。

## 7. 行为、车道和目标空隙

### 7.1 为什么先搜索拓扑

高速交通中的核心选择通常不是一个连续数值，而是离散关系：

- 留在当前车道还是进入左侧或右侧车道。
- 在目标车道某辆车之前通过，还是在其后方并入。
- 继续跟随当前前车，还是寻找更有利的目标空隙。

这些选择会改变障碍物的前后约束关系。若将它们直接塞进一个连续优化器，容易得到非凸、不可解释或在周期之间跳变的结果。因此，规划器先枚举少量有明确交通语义的候选，再分别求解连续轨迹。

### 7.2 空隙是有身份的拓扑对象

目标空隙由目标车道以及前后边界车辆共同定义。稳定的障碍物 ID 和跨周期跟踪用于保持空隙身份，避免仅按瞬时距离排序造成目标跳变。

候选一旦声明进入某个空隙，其 ST 约束就必须保持对应的通过顺序。优化过程中不能为了获得数值解而静默切换到另一个空隙。

### 7.3 当前车道巡航是一等候选

当前车道巡航不是废弃代码，也不是绕过新框架的特殊分支。它是一个完整候选：

```text
Behavior   = KeepLaneCruise
TargetLane = CurrentLane
TargetGap  = CurrentLaneLongitudinalCorridor
```

它与变道候选共享输入快照、预测、纵向优化、完整轨迹生成和最终硬校验。这样才能同时满足：

- 作为可重复的基线进行效果比较。
- 在主动候选不满足保守条件时继续提供稳定控制。
- 避免所谓“安全回退”反而绕过新的安全规则。

车道巡航只有在自身通过校验时才能作为回退轨迹；它不是无条件安全的。

## 8. 保守变道准入

变道候选在进入昂贵的路径和 QP 求解前，先经过保守准入门。准入门的职责是拒绝证据不足的变道，而不是证明变道最终安全。

准入至少考虑：

- 目标车道在整个变道区间内连续、可行驶且不存在即将结束或强制分流。
- 目标空隙的前车距离、后车距离、相对速度和碰撞时间具有足够余量。
- 前后车辆的预测不确定性、感知误差、控制跟踪误差和规划延迟已计入余量。
- 在自车可能横跨两条车道的整个时间区间内，两条车道均不存在物理占用冲突。
- 后车即使按保守加速度接近，自车仍不会迫使其进行不合理的强制制动。
- 自车具备完成变道所需的纵横向动力学余量。
- 在尚未越过不可逆边界前，仍保留继续等待或返回当前车道的空间。

可将鲁棒间距理解为：

```text
RequiredGap = PhysicalClearance
            + PredictionUncertainty
            + LocalizationAndTrackingError
            + ControlExecutionError
            + PlanningLatencyReserve
            + AdditionalConservativeBuffer
```

这些项不能被一个看似较大的固定距离简单替代。速度越高、预测越不稳定、执行误差越大，所需余量就应越大。

准入采用“证据不足即拒绝”的原则。障碍物身份不稳定、目标空隙边界缺失、预测分歧过大或地图语义不确定时，保持当前车道，而不是尝试用优化器赌出一条轨迹。

## 9. 固定空间路径

### 9.1 路径只描述空间几何

每个通过准入的候选生成一条固定空间路径：

```text
r_C(p) = [x_C(p), y_C(p)]
```

其中 `p` 是沿该路径的实际物理弧长。保持车道候选沿当前车道中心或其平滑延续前进；变道候选使用满足起终端横向位置、方向、曲率和曲率变化趋势连续性的七次空间曲线。

实现可以先在单调道路参数上构造七次曲线，再按实际弧长重新参数化，但向下游暴露的 `PathProgress` 必须始终具有物理弧长语义。

七次曲线的起点边界必须从规划前沿至少四个已保留路径状态继承 `d,d',d'',d'''`。当模拟器回灌坐标与内部路径存在允许范围内的毫米级残差时，必须先把已下发的平滑 Cartesian 状态变换到与回灌末端相同的刚性坐标帧，再投影并估计这些导数，不能直接沿用未修正的名义 `planned_d`。终点边界为目标车道中心及零 `d',d'',d'''`。这里的 C3 是可计算的连接契约，而不是仅检查位置接上；起点证据不足或采样间距退化时应拒绝候选。重新参数化后的几何表还必须保留 RoadS、FrenetD、Cartesian位置、单位切向、曲率和曲率变化率之间的确定映射。

### 9.2 为什么不用固定时间横向曲线

早期方案中的 `d(t)` 会把横向形状和纵向速度过早绑定：

- 自车减速或停车时，时间仍在推进，横向轨迹可能继续穿越车道。
- 纵向 QP 改变速度后，车辆实际经过的空间曲线随之改变。
- 障碍物投影、碰撞检查和纵向优化相互耦合，难以独立验证。
- 每次速度调整都可能要求重新求解横向轨迹。

固定空间路径 `d(p)` 或等价的 `r_C(p)` 将几何与时间解耦。纵向优化只决定 `p(t)`，减速时横向进度自然减慢，停车时横向运动也停止。

### 9.3 路径自身的可行性

空间路径在进入纵向优化前先检查：

- 道路边界和禁行区域。
- 路径连续性、航向连续性和曲率上限。
- 车辆包络在路径上的静态可通行性。
- 与候选声明的目标车道和目标空隙一致。

横向加速度还取决于速度，必须在纵向求解和最终轨迹校验中继续检查，不能只靠几何路径判定。

进入纵向优化前可以先使用候选速度上界做保守预检查：`a_lat = v²|κ|`，横向 jerk 上界同时计入 `v³|dκ/dp|` 与 `2v|a_lon||κ|`。道路边界检查使用带航向的车辆本体包络，而不是只检查路径中心点。预检查通过只说明该固定几何值得进入ST/QP阶段，不能替代求解后的完整Cartesian动力学与碰撞硬校验。

## 10. 候选专属的交通预测与 ST 约束

规划器首先对所有相关车道中的前车、后车和潜在切入车辆进行跟踪和预测。预测输出不是单条绝对真值轨迹，而是带不确定性的占用包络；存在多个合理运动模式时，使用保守并集或明确的多模态分支。

对每条候选路径，障碍物占用被投影为随时间变化的 `PathProgress` 禁止区间：

```text
ObstacleEnvelope(x, y, t)
        -> project onto r_C(p)
        -> ForbiddenPathProgressInterval(t)
```

不同候选路径具有不同的投影和不同的 ST 走廊，因此不能让所有候选复用当前车道的一维前车约束。

目标空隙定义通过顺序，ST 走廊把该顺序转化为纵向边界。例如，选择在目标后车之前、目标前车之后并入，就必须同时满足后边界和前边界，并在整个横向占道区间保留鲁棒余量。

ST 走廊用于高效求解和提前拒绝不可行候选，但它仍是中间模型。最终物理碰撞结论由笛卡尔轨迹校验器给出。

## 11. 纵向 QP

空间路径固定后，纵向 QP 求解 `p(t)`，典型状态为位置、速度、加速度和 jerk。它综合考虑：

- 离散时间动力学一致性。
- 速度、加速度、减速度和 jerk 限制。
- 候选路径曲率对应的速度上限和横向加速度限制。
- ST 前后边界及鲁棒跟车距离。
- 期望巡航速度、通行效率、舒适性和解的平滑性。
- 与上一周期已提交轨迹之间的连续性。

优化目标只在安全可行域内比较舒适性和效率。物理碰撞、道路边界和车辆基本动力学约束不能通过代价权重买掉。

某些运营层余量可以设计为受控软约束，用于区分“舒适余量不足”和“数学上完全无解”；但任何 slack 都不能把车辆物理重叠变成可发布轨迹，且其使用必须进入诊断和降级逻辑。

## 12. 完整轨迹合成与硬校验

QP 输出后，规划器按每个时间采样点计算：

```text
p(t) -> r_C(p(t)) -> x(t), y(t), heading(t), curvature(t)
```

由此得到完整笛卡尔轨迹。统一校验器随后检查整个规划时域，而不只是控制即将消费的前缀。

硬校验至少覆盖：

- 时间戳单调、数值有限、采样连续。
- 与保留轨迹前缀的状态和几何连续性。
- 车辆包络始终位于可行驶道路范围内。
- 与进入控制碰撞门的预测障碍物占用包络不存在物理重叠。
- 速度、纵向加速度、横向加速度、总加速度、jerk 和曲率满足边界。
- 候选没有违反其声明的车道、空隙和通过顺序。
- 变道占道期间满足额外的前后车鲁棒余量。

中间 QP 的“求解成功”只表示数值模型有解。只有完整轨迹通过硬校验，才表示该候选可进入普通候选排序；显式最小风险输出使用独立分类和风险排序，不能混入普通排序。

当前车道巡航对同车道后车采用明确的责任边界：若车辆在当前观测帧与自车车道索引相同，且计入本体长度、物理裕量和校验容差后车身已完全位于自车后方，则该车辆的整条未来时间线不进入控制硬碰撞门，也不能触发减速或 `MinimumRiskDispatch`。其 ID 必须保留在诊断中。当前已接触/重叠的后车、前车、相邻车道车辆及车身侵入对象不适用该屏蔽；全车道 Shadow 仍继续跟踪后车并用于变道间隙和后向 TTC 判断。

## 13. 候选排序与状态提交

候选选择采用分级规则，而不是用一个总成本让收益抵消安全风险：

1. 首先剔除所有硬约束不通过的候选。
2. 在可行候选中优先选择安全余量更大、预测更确定的候选。
3. 在安全水平接近时优先保持上一周期意图，抑制频繁切换。
4. 最后比较通行效率、速度跟踪和舒适性。

变道需要额外的进入阈值和保持滞回。主动变道的收益必须显著高于继续巡航，才允许从基线候选切换；一旦开始执行，也不能因为微小成本变化立即反向选择。

所有候选评估必须无副作用。只有最终获胜候选可以提交：

- 下一周期使用的拼接轨迹。
- 候选身份和行为状态。
- 与该候选对应的 QP 暖启动状态。
- 变道承诺与阶段状态。

失败候选不得污染后续周期。

## 14. 当前运行模式

| 模式 | 控制输出 | 行为候选 | 主要用途 |
| --- | --- | --- | --- |
| `LaneCruiseOnly` | 仅当前车道巡航 | 不运行或不参与控制 | 基线、初始部署、安全功能建设 |
| `BehaviorActive` | 所有通过硬校验的候选均可竞争 | 可主动控制 | 保守开启高速领航行为能力 |

模式切换只改变候选是否有资格控制车辆，不改变物理安全标准。

关闭主动模式时先禁止发起新变道。若车辆仍处于 `KeepLane` 或跨线前的 `Prepare`，可以选择已验证的保持车道候选后切换；若已经 `Committed`，则继续保留完成、减速完成和独立验证中止所需的主动执行能力，进入目标车道并稳定后才完成模式降级。运行模式开关不能清除已经承诺的行为状态。

## 15. 回退与不可避免碰撞

回退遵循“仍然通过同一安全判定”的原则：

- 主动候选失败，而车道巡航候选有效时，选择车道巡航。
- 正常巡航不可行，但存在安全减速或停车轨迹时，进入受控降级。
- 输入质量不足时，禁止新变道并收缩到保守巡航或减速策略。
- 当前帧车身已完全位于自车后方的同车道车辆不构成制动回退输入；后向风险由诊断和行为层处理，不能反向触发最大制动。
- 所有无碰撞候选都不可行时，显式进入 `CollisionUnavoidable`，通过独立的 `MinimumRiskDispatch` 降低碰撞概率或严重度并上报状态。

禁止通过清空障碍物、放松物理碰撞约束或复用未经校验的旧轨迹制造“成功”结果。`CollisionUnavoidable` 不是普通可行轨迹，也不能在指标中被统计为规划成功。

MinimumRiskDispatch 仍必须运行完整校验并记录不可满足项。它只在已证明不存在普通有效候选后参与风险分级，优先减少碰撞对象、推迟首个碰撞时刻、降低相对碰撞速度和重叠程度；它不能因为“必须输出”而获得 `valid=true`。

## 16. 一个典型决策过程

假设当前车道存在慢车，左侧车道存在一个较大的前后车空隙：

1. 规划器始终生成当前车道巡航候选。
2. 行为层识别左侧目标车道及其前后边界车辆，形成目标空隙候选。
3. 保守准入根据后车接近速度、预测误差、变道时长和执行余量判断是否值得继续。
4. 若准入失败，只保留巡航，不让 QP 尝试“挤进去”。
5. 若准入通过，为该空隙生成固定空间变道路径，并建立候选专属 ST 走廊。
6. 纵向 QP 可以选择提前减速、等待后车通过，或在充足余量下进入空隙。
7. 两条候选都合成为完整笛卡尔轨迹并接受相同硬校验。
8. 只有变道候选安全余量充分、收益显著且状态稳定时，主动模式才允许它胜出。
9. 只有最终获胜候选可以提交跨周期状态并产生控制输出。

这个过程体现了方案的保守性：变道不是“找到一条勉强无碰撞的轨迹就执行”，而是只有证据、余量和收益都充分时才获得控制资格。

## 17. 正确性的边界

### 17.1 条件性安全结论

在以下假设同时成立时，可以对已发布轨迹在有限规划时域内给出条件性安全结论：

- 地图道路边界和车道关系正确。
- 感知没有遗漏关键障碍物。
- 实际障碍物运动落在使用的预测占用包络内。
- 自车定位、尺寸和执行跟踪误差不超过设计余量。
- 候选路径映射、ST 投影和完整轨迹校验实现正确。
- 控制器能够在约定误差内跟踪已发布轨迹。

在这些条件下，发布轨迹通过车辆包络级碰撞校验，意味着它在所校验时域内不与预测占用发生重叠。

### 17.2 不能承诺的事项

规划器不能单独保证：

- 感知漏检、错误分类或严重定位跳变下仍然无碰撞。
- 障碍物采取预测包络之外的突发行为时仍然无碰撞。
- 超出有限规划时域后的长期全局安全。
- 车辆已处于物理不可恢复状态时仍能找到无碰撞轨迹。
- 执行器、制动系统或底盘不满足模型假设时仍然按计划运动。

因此，滚动重规划、运行时监控、控制跟踪监控和明确降级状态仍是完整安全闭环的一部分。

## 18. 必须长期保持的系统不变量

- 所有控制候选使用同一份不可变周期快照。
- 所有实际下发轨迹都运行同一个完整时域硬校验器；只有普通有效候选要求校验全部通过，MinimumRiskDispatch 必须显式保留违规结果。
- 普通候选的物理碰撞约束永远不能被 cost 或 slack 抵消；MinimumRiskDispatch 只能显式量化不可避免违反，不能改变边界或重新分类为 valid。
- 同车道后车屏蔽只允许在当前帧车身已完全位于自车后方时生效，并必须记录对象 ID；前车、相邻车、侵入车和当前本体重叠不得借此绕过硬门。
- 当前车道巡航也不能绕过新的安全链路。
- 失败候选永远不能提交拼接、行为或暖启动状态。
- 只有最终获胜候选可以产生跨周期副作用。
- MinimumRiskDispatch 只能更新紧急状态和实际输出继承信息，不能提交失败普通候选的行为意图。
- 变道证据不足时默认拒绝，不依赖优化器冒险补救。
- 保留轨迹前缀必须有上限，并持续接受安全检查。
- 规划失败必须显式暴露，不能通过删除障碍物伪装成功。
- 已承诺变道必须先安全完成或独立验证中止，再完成运行模式降级。

这些不变量比具体算法、权重或阈值更稳定。未来替换预测器、路径生成器或 QP 求解器时，也必须继续成立。

## 19. 方案优势与主要限制

### 19.1 优势

- 复用纵向 QP、轨迹拼接和巡航能力，减少重复实现。
- 离散拓扑可解释，便于复现某次变道选择和失败原因。
- 固定空间路径与纵向时间参数解耦，便于分别调试和验证。
- 当前巡航和主动候选共享安全基础，比较更公平。
- 保守准入可以在能力尚不成熟时限制暴露面。

### 19.2 限制

- 候选集合有限，可能错过需要联合复杂横纵向博弈的最优解。
- 保守预测并集可能导致较多误拒绝，降低变道效率。
- 固定空间路径对强交互中的临时横向调整能力有限。
- 多候选完整预测、QP 和校验会增加周期计算量。
- 正确性高度依赖坐标语义、障碍物跟踪和候选专属投影的一致实现。

这些限制是有意接受的取舍。方案优先保证可解释、可回退和可验证，再通过回归数据改善效率，而不是追求激进的变道成功率。
